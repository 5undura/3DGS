# 3단계: Brush 학습

Brush 앱(`brush_app.exe`)으로 학습함. CLI도 있음 (`brush_app.exe --help`).

## 순서
1. Brush 실행 → 데이터 폴더로 `Nb\data` 선택 (안에 `images`, `sparse\0` 이 있어야 함)
2. 아래 설정으로 학습
3. 내보낸 PLY는 `Nc` 폴더에 저장 (`export_30000.ply` 가 최종)

## 우리가 쓰는 설정
| 항목 | 값 | 비고 |
|---|---|---|
| 해상도 (최대 이미지 크기) | 1920 | 4K는 학습이 무너진 적 있음 (방 5: 스플랫 3.5만 개로 붕괴) |
| 최대 스플랫 수 | 3,000,000 | 복도는 6,000,000 버전도 있으나 VR에서 끊김 → 3M 권장 |
| SH 차수 | 2 | |
| 스텝 | 30,000 | 5,000 스텝마다 중간 PLY 저장 |

## 확인
- SuperSplat(https://superspl.at/editor)에 PLY를 끌어다 놓으면 바로 확인 가능
- Unity: aras-p UnityGaussianSplatting 플러그인으로 PLY → 에셋 변환

## 설정 실험 기록 (해결 방향 3, 2026-11)
Brush 에서 쓸 수 있는 관련 옵션: `--scale-loss-weight`(크기 벌점), `--growth-grad-threshold` / `--growth-select-fraction`(스플랫 늘어나는 정도).
배경 무작위화는 Brush 에 없음 → `colab/` 노트북(gsplat)에서 테스트.

방 6, 나머지 설정은 기존과 동일 (`tools/ply_stats.py` 로 측정):

| 버전 | 바꾼 것 | 스플랫 수 | 바늘형(>10배) | 큰 스플랫 상위 1% 길이 | 반투명(<0.5) |
|---|---|---|---|---|---|
| A 기존 | - | 164만 | 12.6% | 0.53 | 95% |
| B | scale-loss 1e-7 | 146만 | 18.3% | 0.47 | 95% |
| C | scale-loss 1e-6 | 133만 | 15.4% | 0.32 (−40%) | 95% |
| D | growth 0.00002 / 0.2 | 300만 (상한) | - | - | - |

- 크기 벌점은 모양(바늘)이 아니라 크기만 줄임. 반투명 비율은 어떤 설정으로도 그대로
- 방 6 은 원래 줄무늬가 적어 눈으로는 차이 없음 → **실험은 줄무늬가 심한 복도에서 할 것**
- 방 6 은 Colab(gsplat 기본 학습, Difix 보정)으로도 돌려 봤으나 floater·덕지덕지한 질감 때문에 Brush 기본 설정이 가장 나았음. 줄무늬 없는 방이라 Difix 효과는 판단 불가 → 복도에서 재확인 예정
- E (C + D) 로 구간 1~6 학습 → `brush_experiment.ps1`. 복도에서는 성장 강화 때문에 3,500 스텝에 300만 상한 도달

### 2DGS (해결 방향 2, 복도 1)
`colab/gs2d_colab.ipynb`, T4, 960 폭, 30,000 스텝, SH 2 → 약 1시간 30분.
- 결과: 표면이 매끈하게 뭉개져 메쉬처럼 보이고 얼룩·질감·세부 구조가 사라짐
- 원인 추정: 2DGS 는 화질보다 표면 형태를 우선하는 방식(법선 손실로 평평하게 폄) + Colab RAM 때문에 Brush(1920)의 절반 해상도로 학습 + **스플랫 약 51만 개**(Brush 300만의 1/6, 2DGS 기본 설정은 상한 없이 이 정도에서 멈춤)
- 줄무늬·비침 감소 여부는 아직 확인 전 (옆벽 비스듬한 각도, 분홍 배경으로 `splat2\1.ply` 와 비교할 것)
- 결과 PLY: 드라이브 `3DGS/colab/out/corridor1/gs2d/ply/corridor1_2dgs_{10000,20000,30000}.ply`

### Difix (해결 방향 4, 복도 1)
`colab/difix_colab.ipynb`, T4, 960x540, gsplat MCMC 300만 상한. ① 기본 30,000 스텝 → ② Difix 보정 60,000 스텝까지 (4,000 스텝마다 8라운드, 좌우 15°→60° 돌린 각도 약 120장씩 보정).
비교 이미지 `3DGS/colab/out/corridor1/compare.png` (카메라 4곳 × 정면·45°·70°, 분홍 = 비어 있는 곳):
- 옆 각도에서 벽의 번짐·검은 얼룩이 눈에 띄게 줄고, 문·배전반·게시판 윤곽이 또렷해짐
- 바닥·벽의 분홍(비어서 배경이 보이는 곳)도 대부분 줄었음. 다만 천장 쪽 분홍 얼룩과 70° 로 벽에 바짝 붙은 화면의 뭉개짐은 남음
- 주의: 비교 각도(45°)가 Difix 가 보정에 쓴 각도 범위(최대 60°) 안이라 유리한 비교임 → VR 에서 실제로 걸어 다니며 확인 필요
- 결과 PLY: 드라이브 `3DGS/colab/out/corridor1/ply/corridor1_{base,difix}.ply` (각 300만 개, 492MB)
