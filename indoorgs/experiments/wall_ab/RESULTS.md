# wall_ab — 학습 후 벽 파이프라인(snap → cleanup → repair)이 3DGS 화질을 올리는가 (CPU mini3dgs, 2026-11-27)

## 결론 (먼저)

- **초기 점 심기(seed, 변형 B)만 확실히 좋음**: 테스트 PSNR 35.23 → **38.26 dB**, 새 시점(VR) 31.55 → **34.81**, 비스듬히 본 시점 23.4 → 26.9.
- **학습 후 단계는 기본값 그대로면 PSNR 을 깎음.** B 기준 raw 38.26 → snap 36.72 → cleanup 35.98 → repair(텍스처) 35.92.
  새 시점도 34.81 → 33.27. 비침(분홍 배경)은 1.96% → 3.90% 로 **두 배**.
- 도움이 되는 건 **cleanup 의 floaters(부유물 지우기) 하나**: 비스듬 시점 PSNR A +2.95 / B +0.76 dB, 입사각 70° 넘는 픽셀
  A 19.0 → 23.4 dB, 포스터 옆 흰 벽의 렌더 깊이 오차 −20.6 → −5.4 cm. 대신 테스트 PSNR A −1.4 / B −0.6.
- snap 의 손해 대부분은 **납작하게 하기(flatten)** 에서 옴 (B 테스트 −1.57 dB, 비침 1.96 → 3.35%). 벽 뒤 지우기는
  안전장치(2%/20%) 덕분에 거의 안 지워서 영향이 작지만, 안전장치를 끄면 A 에서 −7.3 dB(비침 10.5%)로 망가짐.
- **버그 2개** (아래): snap 색 검사가 거꾸로 동작함(포스터 색이 '벽 색'이 됨), refine 이 튀어나온 포스터 쪽으로 면을 기울임.
- 포스터 깊이: snap 은 포스터를 벽에 거의 안 붙임. 하지만 지켜진 쪽은 **흰 종이 부분**이고, **색 부분이 벽 쪽으로 당겨짐**
  (B·실제 면: 중앙 2.6 → 0.7 cm, 36% 가 벽 위 5 mm 안) — 버그 1 때문.

## 장면·설정

- `scene.py`: 6 x 2.4 x 2.7 m 복도 + 문(0.9 x 2.1 m, 벽 두께 0.1 m)으로 이어진 3.55 x 3.0 x 2.62 m 방. 미색 벽(아주 약한 얼룩),
  걸레받이·스위치·비상구 표지·칠한 닫힌 문 2개, **복도 벽에서 2.5 cm 튀어나온 포스터**(위 70% 색 그림, 아래 30% 흰 종이),
  방 벽에서 2 cm 튀어나온 액자, 30 cm 타일 바닥, 60 cm 텍스 천장 + 조명 5개. 광선 추적 정답(시점 무관 색).
- 도면(plan.json) 줄자 오차 흉내: 방 동쪽 벽 실제 6.05 (도면 6.00), 방 천장 실제 2.62 (도면 2.60).
- 카메라 128장 384x240 (손에 든 스캔: 복도 걸으며 좌우 벽·천장·바닥, 문 지나 방 둘러보기, 나와서 반대로). 학습 112 / 테스트 16.
- 초기 점(A): 밝기 기울기 > 25 인 픽셀만, 사진마다 점 수 ∝ 무늬 픽셀 수, 1.5 cm 잡음, 2% 허공 점 → 5,885 개. 흰 벽 가운데엔 없음.
- 면 맞추기(refine, 실제 파이프라인과 같은 호출): 12 면 중 **8 면만 맞춤**. 못 맞춘 4 면(복도 동쪽 끝·북쪽(문·표지 있는 벽),
  방 남쪽·북쪽)은 전부 **흰 벽** = 정작 문제인 벽에는 snap·repair·seed 가 안 들어감.
- B: `seed.seed_points(맞춘 8면, spacing 0.08)` → 13,689 점 추가 → `write_seeded_model` (stages/walls.py 와 같음).
- 학습: mini3dgs 2,500 반복, 256x160, SH 2, cap 100k, seed 0, 검정 배경, 2 스레드 (A 16 분, B 16 분).
- 후처리 = stages/snap.py 와 같은 인자, 누적: snap(맞춘 면, band 0.03, color_tol 0.12, 벽 뒤 지우기 켬) → cleanup(모든 면 + plan +
  카메라 + 모델, 기본 4단계) → repair(snap 이 쓴 면, 카메라, min_cover 0.5, max_hole 4 m²) / repair + facetex 텍스처.
- `_oracle`: 같은 PLY 에 **실제 면 12개**(refine 이 완벽했다면)로 같은 후처리.
- 평가 (`run.py eval`): 테스트 16장, 새 시점 112장 = vr_cameras(옆·위아래 ±0.3 m 60장, ±60° 32장) + 벽을 10~25°로 스치는 20장.
  - 비침 = 분홍 배경에서 분홍이 5% 넘게 섞이는 픽셀 비율 (= 1 − 누적 alpha > 0.05; 닫힌 장면이라 정답은 어디나 면).
  - 입사각>70° 픽셀 PSNR = 새 시점 전체에서 정답 면을 70° 넘게 비스듬히 보는 픽셀만 모은 PSNR (줄무늬 대용).
  - 벽 두께 = `snap.splat_flatness(실제 면).wall.rms_thick`. 포스터 깊이 = 포스터 정면 1.5 m 시점의 렌더 깊이 − 정답 (포스터 / 옆 흰 벽).

## 발견한 버그·나쁜 기본값

1. **snap 색 검사가 거꾸로 동작** — `walls/snap.py:135-178` `wall_colors`. 칸(1 m)별 '벽 색' = 가우시안 개수 기준 중앙값인데,
   무늬 있는 물체는 흰 벽보다 m² 당 가우시안이 훨씬 많음. 포스터는 칸 면적의 48% 인데 그 칸 불투명 가우시안의 87%(A 595/681) /
   81%(B 907/1120) 가 포스터. 그래서 포스터 칸의 '벽 색' = 포스터 파랑 (A [0.03, 0.17, 0.29], B [0.18, 0.31, 0.50]).
   A 는 면 전체 중앙값까지 파랑 [0.17, 0.31, 0.54] (흰 벽 가우시안이 ±3 cm 띠 밖에 많아서). 결과: 포스터 **색 부분**은 붙여지고
   (위 표), 흰 벽·흰 종이는 '색이 달라서' 건너뜀 (A 맞춘 면: 붙임 4,643 vs 색으로 건너뜀 6,183). 138행 주석 "절반을 넘지 않으면
   중앙값은 벽 색" 의 가정이 틀림. 고칠 방향: 면적 가중(가우시안 2D 크기 × 불투명도) 중앙값, 또는 칸 안 색 군집 중 가장 넓은 것,
   또는 facetex 텍스처의 저주파 색을 기준으로.
2. **refine 이 튀어나온 물체 쪽으로 면을 기울임** — `walls/refine.py:150` `inlier_thr=0.03` + `:124` IRLS 차단 `3*thr`(9 cm).
   흰 벽에는 점이 없어서 포스터 앞면 점이 그 벽 점의 53%(437/829) → corr:w0 이 0.76° 기울고 1.0 cm 이동, 실제 벽과 모서리 차
   **+4.5 / +1.5 / +0.5 / −2.6 cm**. 포스터 점을 빼면 +1.3/+1.3/−0.3/−0.3 cm. 액자 벽(room:w3)도 +0.6~+2.1 cm. `inlier_thr=0.015` 로
   하면 corr:w0 는 맞추기 실패(도면 그대로). 기울어진 면 + band 3 cm 이면 벽 한쪽 끝은 안 붙고 다른 쪽은 엉뚱한 면에 붙음.
   고칠 방향: 맞춘 면에서 한쪽(방 안쪽)으로만 몰린 점 무리 제외, 또는 RANSAC 뒤 '가장 뒤쪽 층'(방 밖 쪽 봉우리)을 선택.
3. **흰 벽 면은 거의 못 맞춤 (설계 한계)** — 12 면 중 맞춘 8 면은 무늬가 있는 면(포스터·문·바닥·천장)뿐, 흰 벽 4 면은 점 부족/
   덮임 부족(`min_coverage 0.25`, 모서리 띠 0.15 m 가 걸레받이 점(바닥 0.1 m)을 다 뺌). 그래서 seed·snap·repair 모두 정작 흰 벽엔 안 들어감.
   그래도 B(seed) 가 +3 dB 인 것은 바닥·천장·무늬 벽에 심은 점 덕분.
4. **벽 뒤 지우기는 실제 면에서도 해로움** — 학습된 3DGS 는 무늬 없는 흰 벽을 벽 뒤 15 cm 넘는 곳의 가우시안으로도 그림
   (A 불투명의 14%). 이것을 지우면 구멍(비침)이 남음: 실제 면·안전장치 끔에서 테스트 −11.5 dB, 비침 17%. 지금 기본값
   (`snap.py:61-62` 2%/20%)이 이걸 막아 주는 셈이라 **안전장치를 풀지 말 것**. 경고문 "도면 면이 실제와 다를 수 있음" 은 이 장면에서는
   틀린 진단(면은 맞음 — 실제 원인은 벽 뒤 가우시안이 벽을 그리는 중).
5. **repair 가 덮임을 띠(±6 cm) 안만 셈** — 벽을 뒤쪽 가우시안이 그리는 A 에서는 멀쩡해 보이는 벽을 '구멍'으로 보고 1,904 개를
   얹음 → 비침은 1.1 → 0.8% 로 줄지만 PSNR −2.1 dB (텍스처 색 써도 −0.8). `hole_search 0.30` 보다 깊은 뒤쪽 가우시안은 못 봄.
6. `cleanup sh`: 이 장면에서 튐 0 개 (영향 없음). `needles`: 바늘 비율은 줄지만 스침 시점 지표 변화 없음, 개수만 +9~11%.

## 추천 기본값

- `walls.seed = true` (유지): 이 실험에서 유일하게 큰 이득 (+3.0 dB 테스트, +3.3 새 시점, +3.5 스침).
- `walls.snap`: **기본 끄기 권장**, 켜려면 `flatten=False`(옮기기만) — flatten 이 B 에서 −1.6 dB 의 대부분. 학습 뒤 붙이면 색·불투명도는
  두꺼운 가우시안 기준이라 화질이 떨어짐 → 붙인 뒤 짧은 재학습(fine-tune) 이 없으면 이득 없음. 버그 1·2 고치기 전에는 color_tol 도 믿기 어려움.
- `remove_behind`: 켜 둔다면 지금 안전장치(2%/20%) 그대로. 풀면 크게 망가짐.
- `cleanup.steps`: `floaters` 는 켬 (VR 스침 시점·벽 앞 안개에 확실한 이득, 정면 −0.6~−1.4 dB 대가). `huge`·`sh` 는 영향 거의 없음,
  `needles` 는 스플랫 수만 늘림 → 실제 학습기에서 바늘 16% 일 때 따로 재 볼 것.
- `walls.repair`: 끄기 권장 (B 에서 −0.04~−0.4, A 에서 −0.8~−2.1 dB). 켤 거면 `texture=true` 필수 (텍스처 없으면 0.3~2.7 dB 더 나쁨).

## 한계

- mini3dgs 2,500 반복 256x160, 불투명도 리셋 없음 → 반투명 비율이 높음(0.52~0.61). 실제 Brush 30k / 1920 px 와 절대값 다름.
  같은 설정끼리 A/B 비교만 의미 있음. seed 1개 (반복 실험 안 함, 차이 0.2 dB 이하는 잡음으로 볼 것).
- 정답 색은 시점 무관 (반사 없음), 카메라 자세는 정답 그대로 (정합 오차 없음).
- 학습 배경 검정. 비침은 alpha 로 계산 (분홍 합성과 수학적으로 같음).
