## 결론 (먼저)

1. **면 맞추기 수정이 가장 큰 이득.** 맞춘 면 8 → **12/12** (흰 벽 4면도), 포스터 벽 모서리 오차 4.5 → 0.5 cm.
   그 면에 seed 하면 **B raw 38.26 → 38.86 dB (새 시점 34.81 → 36.04, 스침 26.90 → 28.78)**. A 대비 +3.6 / +4.5 / +5.4 dB.
2. **학습 뒤 후처리만 하면 여전히 손해**, 오히려 더 큼 (B snap 기본값 −4.4 dB, 비침 1.9 → 7.3%). 버그 1을 고치니 이제 흰 벽이
   제대로 붙여지는데, 학습된 흰 벽은 면 뒤 가우시안 조합으로 그려져 있어 붙이기·지우기가 그 조합을 깨기 때문.
3. **후처리 + 짧은 재학습(1000 반복)은 raw + 같은 재학습보다 나음** (공정 비교):
   - B(seed): snap(기본: 지우기+옮기기+납작하게) + FT = **테스트 +0.24, 새 시점 +0.32, 스침 +0.92, 입사각>70° 픽셀 +0.88 dB,
     벽 두께 4.56 → 2.74 cm, 반투명 0.539 → 0.515**. 비침만 1.70 → 2.10% 로 조금 나빠짐. 300 반복에서는 테스트 −0.19 (스침은 +0.93),
     600 부터 모두 이득. 이득의 원천은 **납작하게**: 옮기기만 + FT 는 raw + FT 와 같음 (39.47 vs 39.57).
   - A(seed 없음): 부유물 지우기 포함 묶음(rec) + FT = **+0.92 / +1.41 / +2.20 dB** (raw+FT 대비). snap 만 + FT 는 −0.37.
   - 납작하게 정규화 재학습(raw + 손실에 짧은 축 길이, λ=1): +0.07 / +0.19 / +0.72, 두께 4.16 cm — snap+FT 보다 약함.
4. 그래서 **기본값**: seed·면 맞추기 켬 (새 refine 기본), 학습 뒤 `snap`·`repair`·`remove_behind`·`flatten` **끔**,
   `cleanup.steps = [floaters]`. 파이프라인에 재학습 단계가 생기면 그때 `snap: true, flatten: true` + FT 를 켜는 것이 맞음 (아래 E 절).
5. 실제 학습기: **Brush 0.3 은 `init.ply` + `--start-iter` 로 가능**, **LichtFeld v0.5.4.3 은 `--init <ply>` (일정은 처음부터)**. 아래.

- 비침은 B snap+FT 가 raw+FT 보다 0.4%p 나쁨 (지운 550 개 자리). 벽 뒤 지우기를 빼고 FT 하는 조합은 이번에 안 잼.
- 납작 정규화 FT(학습 손실만 바꿈)는 일부 효과 (스침 +0.72) 지만 snap+FT 보다 약하고 두께도 4.2 cm.
- seed 없는 A 에서는 snap+FT 가 손해 (−0.37). seed 로 면이 이미 잘 잡힌 경우에만 snap+FT 가 이득.

### 실제 학습기에서 (E) 가능한가 (소스 확인, PC 에서 `--help` 로 다시 확인할 것)

- **Brush v0.3.0** (`crates/brush-dataset/src/formats/mod.rs`, `crates/brush-process/src/config.rs`, `train_stream.rs`):
  데이터 폴더 안에 **`init.ply`** 가 있으면 (또는 .ply 가 하나뿐이면) 그것을 초기 스플랫으로 씀 — 위치·scale·rot·opacity·SH 모두 읽음
  (`brush-serde/src/import.rs`). **`--start-iter <N>`** ("Iteration to resume from") 로 반복 번호를 이어감 → 예: `--start-iter 30000
  --total-steps 31000`. 밀도 조절은 `--growth-stop-iter`(기본 15000) 전까지만이라 30000 부터면 없음. 주의: 학습률 스케줄러는 상태를
  가진 지수 감소라 `--start-iter` 로 시작하면 **처음 값(`--lr-mean` 2e-5)부터 다시 시작**함 → `--lr-mean 1e-6 --lr-mean-end 1e-6`
  처럼 끝 값으로 주는 것이 위 실험과 같은 조건. 데이터 폴더에 다른 .ply 가 있으면 이름이 정확히 `init.ply` 여야 함.
- **LichtFeld-Studio v0.5.4.3** (`src/core/argument_parser.cpp`, `src/training/training_setup.cpp`):
  **`--init <path>`** "Initialize from a splat, point cloud or mesh file" — 3DGS PLY 면 가우시안 전체를 읽음 (`Loaded N gaussians from ...`).
  반복 수는 `-i/--iter`. 하지만 일정(학습률·밀도 조절)은 0 부터 다시라 '짧은 마무리 학습' 과 같지 않음 — 밀도 조절을 막는 옵션은 소스에서
  못 찾음 (`--max-cap` 을 지금 개수로 주면 늘어나지는 않을 것으로 보이나 미확인). `--resume <.resume|.licht>` 는 LichtFeld 자기 체크포인트만
  (고친 PLY 로는 못 이어감). `--add-splat <ply> --freeze` 는 고정 스플랫 추가용. → **PC 에서 `LichtFeld-Studio --help` 로 확인 필요**.

## 추천 기본값 (config.py 에 반영)

| 설정 | 예전 | **새 기본** | 근거 |
|---|---|---|---|
| refine | 기본 기준만 | `backmost` + `relaxed` 켬 (코드 기본) | 12/12 면, 최대 오차 1.6 cm |
| `walls.trust_plan_dims` | (없음) | **false** | 줄자 오차가 그대로 들어감. 켜면 `infer` 면도 seed/snap/repair 에 씀 |
| `walls.seed` | true | true | +3.6 dB (12면) |
| `walls.snap` | true | **false** | 학습 뒤 단독 −4.4 dB. 재학습 단계가 생기면 켬 |
| `walls.flatten` | (늘 켬) | **false** | snap 을 FT 없이 켤 때 덜 해로운 쪽 (옮기기만 −0.85). FT 와 함께면 true 가 이득 |
| `walls.remove_behind` | true | **false** | 단독 −1.75 dB, 비침 2배 |
| `walls.repair` | true | **false** | 광선 확인으로 손해는 줄었지만 (A −0.67) 이득 없음 |
| `cleanup.steps` | [floaters, huge, needles, sh] | **[floaters]** | seed 없을 때 스침 +2.95, 나머지는 영향 0 (needles 는 개수만 +8%) |

재학습(FT) 을 실제 학습기로 할 수 있게 되면 (Brush `init.ply` + `--start-iter`): `walls: {snap: true, flatten: true, remove_behind: true}`
→ snap 결과로 600~1000 반복 FT 가 이 실험의 최선 (B: 테스트 +0.24, 스침 +0.92, 벽 두께 −40%).
