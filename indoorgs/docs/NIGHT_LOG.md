## 단계별 상세

### Fable 검토 (벽 처리 코드) -> 9개 모두 수정 (테스트 235 통과, 새 회귀 테스트 21개는 수정 전 코드에서 모두 실패 확인)
수학·규약(회전, 쿼터니언, 스케일 축, PLY 순서, 텍스처 방향)은 문제 없음. 실제 버그 8개 (재현 스크립트로 확인):
1. 맞추지 못한 면(도면 그대로)을 믿고 벽 뒤 지우기 -> 도면 천장 2.6 m / 실제 2.8 m 면 실제 천장 100% 삭제
2. 같은 원인으로 repair 가 실제 벽 6~8 cm 앞에 두 번째 벽을 만듦, seed 도 맞추지 못한 면에 심음
3. 설정을 꺼도 낡은 data_seed 로 학습 / 4. fill·merge 가 낡은 splat_repaired.ply 를 고름
5. 두 방이 공유하는 벽에서 한쪽 면이 반대편 면에 맞춰짐 / 6. 문 구멍이 꺾인 벽 조각 하나에만 뚫림
7. "도면 좌표인가" 판정이 단계마다 다름 / 8. planes.json 없을 때 repair 예외
+ 법선 쪽 축이 가장 긴 바늘은 4 mm 점이 됨 -> 바늘 쪼개기에 넘기도록
- 수정 요점: 정합 점으로 맞춘 면(fit)만 지우기·붙이기·심기·메우기에 씀. 지우기 상한(면 이웃 20%, 전체 2%), 바닥·천장은 실제 밀도 봉우리 확인,
  repair 는 ±0.3 m 안에 이미 덮였으면 구멍 아님, data_seed 는 원본 모델 정체(images.bin sha1) 확인 후에만, PLY 선택은 설정·시각 확인,
  등을 맞댄 공유 벽은 방 쪽으로 점 배정, 문 구멍은 구간 겹침, 도면 좌표 판정 통일, 방 안 비율 50% 미만이면 snap 건너뜀.

### 면 텍스처로 메울 색 정하기 — 지운 아이디어 (학습 후 포토샵 채우기처럼)
- `walls/facetex.py`: 벽 면을 1.5 cm 텍셀 이미지로 펼침. 색 우선순위 ① 실제 사진 투영(가림·입사각 검사, 사진별 노출 보정, 여러 장 중앙값)
  ② 어떤 사진에도 없는 곳은 PatchMatch(포토샵 내용 인식 채우기 계열) ③ 생성형 AI 는 나중.
- repair 가 새 스플랫 색을 이 텍스처에서 읽음. `walls/tex/<면>.png` 로 저장 -> 확인용 (고쳐도 다음 repair 에 반영되지만 필수 아님, 자동).
- 합성 측정 (6 x 2.6 m 벽, 타일 + 포스터, 사진 6장, 노출 0.85~1.18 배): 사진이 본 곳 PSNR 50.9 dB (노출 보정 없으면 38.0),
  메우기 오차(0~255) 사진 근처 PatchMatch 3.4 vs Telea 21.2, 좁은 통로로만 이어진 넓은 구멍은 무늬 위상이 틀림(26.5 vs 21.4, 한계).
- 시간: 사진 300장이면 약 50초 (디코드), PatchMatch 3 m² 1.4초.

### CPU 소형 3DGS (평가 도구) — `experiments/mini3dgs/`
- 순수 torch 래스터라이저(EWA, 타일, SH 2차) + 원본 3DGS 식 학습. 기울기를 수치 미분과 대조(상대 오차 < 1e-7).
- 상자 방 1500회: 테스트 PSNR 24.0 -> 32.6 dB, VR 식 새 시점 32.2 dB, 약 10분. 절대값은 실제와 비교 불가, 같은 설정 A/B 전용.

### 벽에 붙이기 수정 — 지운 의견 (액자 등 입체감 보호)
- band 6 cm -> **3 cm**, 그리고 **그 자리 벽 색과 비슷한 스플랫만** 붙임 (면을 1 m 칸으로 나눈 칸별 중앙값 색, 채널 최대 차이 0.12 이하).
- 테스트: 벽 2.5 cm 앞 갈색 액자 200개는 비트 그대로, 흰 벽 스플랫은 95% 넘게 붙음.
- 설정 `walls.band`, `walls.color_tol`.

### 면 메우기 (repair) — 지운 아이디어 (splat-repair 참고)
- 출처: github.com/NicolasDrum/splat-repair (Apache 2.0). `indoorgs/NOTICE`, `indoorgs/licenses/Apache-2.0.txt`, `walls/repair.py` 머리 주석에 고쳐 옮긴 함수 목록.
- 동작: 면마다 5 cm 칸으로 불투명 덮임(광학 깊이 합)을 재고, 덮임 < 0.5 인 칸(비치거나 빈 곳)을 둘레 0.25 m 의 멀쩡한 스플랫을
  **통째로 복사**(크기·회전·SH·불투명도)해 면 위에 놓음. 색은 면의 저주파 색 분포 차이만큼 보정(조명 얼룩 방지).
  학습 카메라가 볼 수 있던 칸만, 4 m² 넘는 구멍은 안 메움 (못 본 넓은 면을 지어내지 않도록).
- 파이프라인: train → snap(벽에 붙이기) → **repair** → fill. 결과 `splat_repaired.ply`, fill·merge 는 repaired > walls > splat 순.
- 합성 측정 (방 3개, 면 20개, 300만 개): 구멍 13.5 m² → 0 (카메라 없음) / 2.2 m² (복도 카메라 400대, 남은 곳은 카메라가 못 본 곳), 약 20초.
- 아직 확인 안 된 것: 실제 화질(PSNR·분홍 배경 비침)에 주는 효과 → CPU 소형 3DGS 로 측정 예정.

## 제안 (구현 안 함, 지운이 오면 물어볼 것)
- ICP: 법선이 반대인 짝 제외 / 바닥으로 높이·기울기만 맞추기 / 기본 끄기 (벽 0.1 m 는 어떤 문턱으로도 못 막음)
- fill: floor_z 를 walls/planes.json(정합 점으로 맞춘 바닥)으로 보정 — 실제 바닥이 도면과 0.1 m 다르면 메운 바닥이 가라앉음
- 동선 GUI "멈춤" 버튼(고정점 2개) 또는 영상에서 멈춘 구간 자동 제안
- diagnose far_from_prior 1 m -> 1.5 m (맞는 정합에서도 0.5~0.9% 빠짐)
- 도면 사진: 색 있는 픽셀은 벽 아님, 바깥 모서리 네 점이면 테두리 닿은 공간도 방으로
- DXF: 문 폭만 한 틈 잇기 또는 경고
- fill 덮임 반경에 학습 스플랫 크기 반영
- **바늘형 스플랫 쪼개기** (비스듬히 볼 때 줄무늬): 벽에 붙은 바늘형(긴 축/중간 축 > 10)을 같은 색의 짧은 스플랫 여러 개로 나눔. repair 기증자에서도 바늘 제외. (11-28 대화에서 물어봄, 답 대기)
- **도면에 없는 물체 보호**: repair 전에 칸을 사진에 다시 투영해 벽 색과 다르면(게시판·소화기 등) 메우지 않음.
